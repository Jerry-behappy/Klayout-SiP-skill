# 复合波导、等长网络与紧凑布局

## 约束与计长口径

- 区分必须保持的拓扑、可移动器件、可调整 crossing、允许改变的弯曲数与只读保留版本。硬约束优先于面积；无解时保留有效版本，报告尚未满足的条件。
- 明确宽度、弯曲类型和参数、taper/过渡长度、净间隔、端口 pitch。截图中的半径参数不一定等于最小曲率半径；曲率与采样数交由 PDK 派生。
- 明确 taper、crossing 的等效贡献，是否包括 EC taper，以及固定器件内部是否计入。项目数值参数化写入任务脚本和报告，不固化成 skill 默认值。
- 区分新增走线转角、固定器件内部曲线、单条开关互连和完整路径。弯曲数按去重复/同向共线点后的有效转角或 PDK 曲线 primitive 统计。

## Path 与完整宽度过渡

从实际 GDS 恢复原始 Manhattan Path，核对端点和方向；不能仅依赖历史 JSON 或 cell 名。修改后用 PDK 正式转换入口创建布局本地 Waveguide/Composite_Waveguide，保留 Path 与恢复元数据。端口宽度角色须与器件匹配。

PDK 可能在容量不足时压缩局部 taper。若要求完整 taper，需预留容量并核对实际 profile，不能悄悄缩短 taper 或降低半径。

若当前 profile 每侧为“窄直段 U + taper T + 宽直段 U”，每侧占用 T+2U；两弯之间另需宽直段 S 时，切点间非弯曲段至少 2(T+2U)+S；宽端口至第一个弯曲切点至少 T+2U+S。原始拐点间距还须加两端曲线切入长度。使用前先核对当前 PDK 的 profile 规则。

“弯间净直段”应说明是切点间全部非弯曲段，还是扣除宽度过渡后的恒宽段；不要用拐点距离代替。

## 分宽度计长与弯曲数

- 核对当前 PDK `length_by_width_um`、`length_um`、`excluded_taper_length_um` 的含义：恒宽段之和可能排除了 taper，与平滑中心线总长不同。
- taper 几何长度与用户等效贡献分别统计，不漏加、不在中心线总长上重复加。crossing 本体及其两端 taper 分开计数。
- 混合宽度按宽度分别匹配。没有有效/群折射率模型时，不将不同宽度几何长度直接称为相同光程；可分别匹配恒宽贡献，其余按用户约定计算。
- 改变曲线、数量或 taper 数后重新求解。报告量化后的最小/最大值和实测差值，不把有限误差称为数学上完全相等。
- 根据端口方向、必经节点和通道判断弯曲数下限。先明确匹配分组：若用户要求同一对相邻列之间的互连等弯曲数，则在各列组内分别匹配，不默认不同列组也必须采用同一个数。各完整路径依次经过相同列组时，再核对各组贡献之和。
- 减少折返后重新补偿长度并验算整个匹配集合；不能只改部分链仍宣称其余路径也满足等弯曲数。
- 多段穿过 crossing 的走线按同一互连链求和。输入输出也纳入全路径；同弯曲数并不自动保证分宽度等长。

## 压缩布局

- 用户点名缩小横、纵间距时，逐组度量实际行列中心距，区别器件边缘间距和波导 Si 净间隔。
- 分别报告阵列、开关互连核心、含 I/O 的整版包围框，不能把核心缩小称为整版缩小。
- 保留版只读，新候选独立命名。无需极限压缩的 I/O 仍须满足长度和弯曲数约束。
- 共享同坐标变量可能造成不必要绑定；需要时改用独立拐点变量，以端口、方向、容量、分离和链等长约束连接。
- 优化器成功只说明模型成立，最终使用实际生成的 Si 几何验收。
- 压缩 S 弯阵列时，保留各路实际偏移和 Bezier 参数，使用 PDK 派生的最小曲率半径筛选横向长度；移动器件后同时处理其公共端引线。配置式脚本与等间距/居中口径见 [sbend-bundles.md](sbend-bundles.md)。

## 针对性验收

- 独立原生重读：PCell 参数、原始 Path、实际宽度/端口截面、完整 taper、派生曲率、余下恒宽直段。
- 用实际 Si region 检查欧氏净间隔与非预期交叠，含不同走线及自身非相邻折返。保持合理的边角过滤；随意提高 `space_check` 角度阈值可能把同一光滑轮廓的邻近采样边误报为间距不足。
- 连接豁免仅用于相应器件、相应端口的局部窗口；不用全局端点掩膜豁免所有器件，也不把起点器件豁免套到终点走线。
- 通过枚举或等价图验证核对所有可达输入输出、链和完整路径的分宽度长度、taper/crossing 贡献及总弯曲数。
- 相关输入未变化时不重复已通过的检查；失败时不提交，针对会改变结论的问题修复。

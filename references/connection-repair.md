# 连接与延时结构修复

## 移相器金属连接

- 先从当前版图和技术文件核对金属层、移相器电极形状及层级；展开实例变换和阵列，区分直接走线、电极接触块与其他器件金属。不要只用 cell 名或图形包围框判断连接。
- 用户明确要求接到最近移相器时，按走线端点与实际电极的几何距离确定候选，结合走线方向、已有网络及器件布局判断。记录匹配和距离；对于等距、多条潜在网络或需要穿越其他金属的情况，不把最近距离自动当作网络证明。
- 改动端点前检查其所属 cell 是否被其他电路引用；仅在目标范围内修改，必要时先隔离共享 cell。保留路径宽度和其余拐点，连接到电极内部，避免只在边界相切造成零面积接触。
- 用实际金属区域检查新增部分对目标电极的接触面积，并检查不同网络、其他电极和相关金属图形是否发生新增交叠。导线包围框重合不能证明图形相交，图形边界相切也不等于具有正面积接触。明确检查覆盖的层级和目标数量，不把局部检查表述为全电路验收。

## 旧版波导与回形针

- GDS 内没有有效 PCell 身份时，先检查可恢复的原始路径属性、端口、器件文字和 Spice 元数据。文字中的宽度、路径和长度是原版图记录；确认坐标变换、实际 Si 截面与用途后才用于重建，不能凭 cell 名猜参数。
- 替换用于补偿的回形针前，确定每条路径的原长度或差分长度、端口位置和方向；改变弯曲模型或半径会改变所需空间和总长。需要时重新布线，并在实际生成几何上核对连接、间距及补偿目标。不同宽度的几何长度不能直接当作相同光程。
- 使用 PDK 正式入口创建波导和回形针；派生参数由 PDK 计算。局部线段长度不足时，PCell 可能缩小实际弯曲半径，须检查每个转角的可用长度，而不能只看参数栏。
- 写出 GDS 后，以独立原生重读核验实际几何、实例变换及恢复路径所需属性；GDS 重读后的静态 cell 或缺失参数不能宣称仍是有效可编辑 PCell。恢复信息未通过核验时停止发布并修复。
- 分阶段候选要明确标注未完成项目，保留输入文件；只有完成要求的光、电连接与相关检查后才能作为最终交付。

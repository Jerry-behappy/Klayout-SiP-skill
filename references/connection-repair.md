# 连接与延时结构修复

## 移相器金属连接

- 先从当前版图和技术文件核对金属层、移相器电极形状及层级；展开实例变换和阵列，区分直接走线、电极接触块与其他器件金属。不要只用 cell 名或图形包围框判断连接。
- 用户明确要求接到最近移相器时，按走线端点与实际电极的几何距离确定候选，结合走线方向、已有网络及器件布局判断。记录匹配和距离；对于等距、多条潜在网络或需要穿越其他金属的情况，不把最近距离自动当作网络证明。
- 改动端点前检查其所属 cell 是否被其他电路引用；仅在目标范围内修改，必要时先隔离共享 cell。保留路径宽度和其余拐点，连接到电极内部，避免只在边界相切造成零面积接触。
- 为加热器一端选择已有馈线时，排除另一端所属的 M2 网络；几何最近的馈线也可能旁路短接加热器。镜像实例的电极中心受 DBU 取整影响可能相差一个数据库单位，应按实际接触面积判断。
- 用实际金属区域检查新增部分对目标电极的接触面积，并检查不同网络、其他电极和相关金属图形是否发生新增交叠。导线包围框重合不能证明图形相交，图形边界相切也不等于具有正面积接触。明确检查覆盖的层级和目标数量，不把局部检查表述为全电路验收。
- 完整电气检查要提取实际 M1 加热支路、M2 连通分量和焊盘开窗之间的关系，覆盖固定开关内部的加热器，不只按某个 heater cell 名统计。分别报告双端馈电、单端断路、两端同网短接和原有未引线支路；原有浮置支路应与输入逐位置比较，不自动并入最近驱动网络。

## 旧版波导与回形针

- GDS 内没有有效 PCell 身份时，先检查可恢复的原始路径属性、端口、器件文字和 Spice 元数据。文字中的宽度、路径和长度是原版图记录；确认坐标变换、实际 Si 截面与用途后才用于重建，不能凭 cell 名猜参数。
- 恢复属性可能仍保留器件移动前的路径。比较恢复路径两端与变换后 PinRec：若两端差值一致，可据实际端口校正整体平移；不一致时需重新查明几何，不能只因属性可解析就使用。
- 替换用于补偿的回形针前，确定每条路径的原长度或差分长度、端口位置和方向；改变弯曲模型或半径会改变所需空间和总长。需要时重新布线，并在实际生成几何上核对连接、间距及补偿目标。不同宽度的几何长度不能直接当作相同光程。
- 端口连接改变时，按“回形针 + 受影响走线”核算补偿链，固定器件锚点后求解内直段、圈数和放置方向。先尝试旋转、镜像和调整相邻走线；不要为使求解通过而暗中缩小指定半径。报告量化后的误差，并区分旧标注目标、几何计长和物理群延时。
- 使用 PDK 正式入口创建波导和回形针；派生参数由 PDK 计算。局部线段长度不足时，PCell 可能缩小实际弯曲半径，须检查每个转角的可用长度，而不能只看参数栏。
- 写出 GDS 后，以独立原生重读核验实际几何、实例变换及恢复路径所需属性；GDS 重读后的静态 cell 或缺失参数不能宣称仍是有效可编辑 PCell。恢复信息未通过核验时停止发布并修复。
- 在 JNU 的本地 Waveguide 流程中，GDS 展开时 PCell variant 的 cell 属性可能丢失；调用 PDK 的实例恢复属性写入逻辑，并在重读后检查实例属性中的路径数据，不只检查 cell 属性。
- 每次中间读写（包括只改金属的步骤）都加载所需库和本地 PCell 声明，保留 GDS context；否则一次中间保存即可丢失原先有效的 PCell 身份。最终重读核对公开库 PCell 和本地波导 PCell 的实际数量及参数。
- 光口坐标匹配后，在对应两端口的局部窗口检查实际 Si 截面连续；只对该连接豁免端口接触区域。大量接缝优先使用递归空间查询裁取局部图形，避免对整网巨型合并多边形重复布尔运算。
- 分阶段候选要明确标注未完成项目，保留输入文件；只有完成要求的光、电连接与相关检查后才能作为最终交付。
## 严格等长版本

- 用户接受并修改过的 GDS 是新基线。先保存其当前副本并从中重建端口图，不沿用旧生成脚本中的坐标或旧计长表覆盖用户改动。明确需要匹配的通道集合，避免将独立参考通道混入阵列。
- 等长按完整端口链计量，包含实际经过的 taper、crossing 和中间直段；同时输出路径端点、完整长度和有效转角数。等弯与非等弯版本可因几何容量使用不同公共目标长度，每个版本分别验收。
- 严格小于 1 nm 时，不能使用界面已四舍五入的长度标签。独立重读后重建与实体同 DBU 量化的中心线求和，使用最大值减最小值判定。细调内直段和拉伸参数后，仍按落格后的几何复核，不以优化器返回成功代替实际满足误差。
- 同时约束转角数、半径容量和空间交叠。若等长解产生交叠，调整放置方向、内直段/拉伸分配和走线通道，再求解并重读；不能交付仅计长满足、几何冲突未消除的版本。
- 热电极消除台阶时，将馈线轴线对齐接触块中心，并覆盖至其内侧端面，保留加热细线本体。接触块可能以短 Path 存储，不能只识别 Box；修改端点及相邻拐点后检查实际覆盖面积和网络关系。

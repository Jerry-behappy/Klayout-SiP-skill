# GDS 修改验证

## 适度验证

检查前明确检测哪种具体失败，以及失败后下一步有何不同。使用能够改变结论的最便宜检查；相关输入未变时，不重复已通过的检查。

不默认创建 SHA、checksum、fingerprint 或哈希清单。仅在用户明确要求、项目已有要求或会影响完整性/并发修改判断时使用。`inspect_layout.py` 默认不计算文件哈希；确有需要时传入 `-rd include_file_hash=true`。

## 验证阶段

1. **读取前**：确认输入绝对路径、版本、大小、修改时间及允许写入的输出。
2. **规划后**：验证目标数量、参数全集、父级和允许变化的字段。
3. **内存修改后**：立即检查每个目标的新状态及不变量。
4. **临时写出后**：用新的 `pya.Layout()` 在完整 KLayout 环境中重读临时 GDS。
5. **提交前**：确认候选通过相关检查，路径正确；已知存在外部保存或版本变化时重新核对，避免覆盖用户新改动。
6. **提交后**：确认结果位于目标路径。复制已独立验证的成品不必再运行整套检查。

## 必查项目

- 顶层 cell、顶层实例数量和整体 bbox。
- 目标实例数量、PCell/library 身份、参数、端口、变换、阵列和父级。
- 非目标实例多重集合。
- 用户点名保护的 Waveguide、spiral、固定器件及其引用数量。
- marker layer 和其他保护层的几何。
- 输出能被 KLayout 成功重读；不能只依赖 `layout.write()` 无异常。

## 绘图专项验收

- Waveguide：确认是真正的布局本地 `Waveguide` 或 `Composite_Waveguide` PCell，`path` 参数可恢复原始 Manhattan Path，项目规定的原始路径层为空，DevRec 符合当前 PDK 的净空规则。
- Composite_Waveguide：检查起始端/终端实际宽度、弯曲宽度、taper 完整位于直段、局部 DevRec、半径降级和 GDS Path 往返。
- Bend/S Bend：检查端口坐标、方向、PinRec、Bezier `B` 的控制点语义和 GDS 重读；Euler 检查 Reff 相关参数而不是隐藏兼容 radius。
- Spiral：检查端口方向、端口处水平 landing、type2 无 jog、type3 等高、`vertical_stretch` 不改变外侧 pitch、`total_length`/`delta_L` 与重读后的只读值一致。
- Basic.Text/Numerical text array：确认每个编号仍是 `Basic.TEXT` PCell，`text`、`layer`、`mag`、bbox 中心距和容器层级符合预期。
- Snap/端口连接：确认只移动允许移动的一组实例，组内相对位置不变，目标端口中心重合且方向相差 180°。
- 等长网络、减少弯曲、复合宽度容量和阵列压缩按 [routing-and-matching.md](routing-and-matching.md) 验收。

## 实例签名

实例签名至少包含：

- PCell：library 名、声明/variant 参数。
- 静态 cell：cell 名及适用的规范化几何/子实例比较；哈希仅在确有需要时辅助使用。
- `cplx_trans`、`na`、`nb`、`a`、`b`。
- 需要跨父级核对时加入父 cell 和实例路径。

对签名使用 `Counter`，保留重复实例语义。

## 几何比较

- 对用户要求完全不变的 cell，可按 layer/datatype、shape 类型、规范化几何和子实例直接比较，不默认生成哈希表。
- 在同一 `dbu` 下比较整数坐标；不要先转浮点微米再比较。
- GDS 记录顺序可能变化，比较前先排序规范化记录。
- 对超大 Polygon 的 record-length 警告可视为非致命，但必须确认输出重读成功且几何/实例验收通过。

## 原位覆盖

原位修改只允许以下顺序：

1. 保留可识别的前版，在目标目录创建临时 GDS。
2. 写出并关闭。
3. 重新读取临时 GDS并完成全部验证。
4. 核对原文件仍是预期版本；若有已知外部修改，先重新核对而非覆盖。
5. 使用 `os.replace(temp_path, input_file)` 原子替换。
6. 不提交失败候选；按需清理自建临时文件，或明确标记为候选/失败状态。

不要先覆盖原文件再验证，也不要在验证失败后把临时文件冒充结果交付。

## 保留版本与回退

- 用户要求保留旧版、新增一版时，生成、验证、发布脚本均使用独立路径；不能只改成品名称而漏掉脚本中的旧覆盖目标。
- 回退时按版本记录选定已验证备份，保留被撤回版；恢复后做能够确认选对版本的原生重读，例如顶层、实例、关键 Path/位置或 bbox，不无故重跑旧版已完成的全部计长/DRC。
- 同步说明中的当前交付与历史版本指向，不能把被撤回候选仍标为最新，也不能用旧报告冒充新文件验证。

## 交付报告

报告实际修改数量、映射/参数、输出路径、保护项、KLayout 重读结果和必要警告。若检测到重复实例、额外目标或用户并发保存，应明确说明并停止，不静默选择其中一部分。
